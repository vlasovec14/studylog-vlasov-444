# Загрузка StudyLog на GitHub

Сначала проверь локальный проект. Для сдачи нужна ссылка на репозиторий исходного кода, а не адрес `127.0.0.1`.

## Создать пустой репозиторий

1. Войди в свой аккаунт на [GitHub](https://github.com/).
2. Нажми **New repository**, название — например `studylog-vlasov-444`.
3. Выбери Public, чтобы преподаватель мог открыть исходники.
4. Не добавляй README, .gitignore или лицензию: они уже есть в локальном проекте, а репозиторий должен оставаться пустым.
5. Создай репозиторий и скопируй HTTPS-ссылку вида `https://github.com/ТВОЙ_ЛОГИН/studylog-vlasov-444.git`.

## Отправить готовую историю

Открой терминал **в папке StudyLog с manage.py и скрытой папкой .git**. Если работаешь с архивом, сначала распакуй его целиком. Git должен быть установлен; при необходимости скачай [Git for Windows](https://git-scm.com/downloads/win).

```powershell
git log --oneline
git status --short
git remote add origin https://github.com/ТВОЙ_ЛОГИН/studylog-vlasov-444.git
git push -u origin main
```

Вместо `ТВОЙ_ЛОГИН` подставь свой реальный логин. При запросе авторизации выполни вход в свой GitHub-аккаунт. Обычный пароль аккаунта не используют как пароль Git по HTTPS; следуй предложенному Git Credential Manager входу через браузер. Не публикуй и не присылай токены.

Если Git не найден в терминале на текущем компьютере, доступна копия Git из Codex:

```powershell
& 'C:\Users\tno_zv\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\git\cmd\git.exe' log --oneline
```

Для остальных команд можно аналогично заменить слово `git` на этот полный путь с `&`.

Если `origin` уже существует, сначала проверь `git remote -v` и убедись, что он ведёт в твой репозиторий. Не используй принудительный push и не удаляй чужую историю. Для этой инструкции нужен новый пустой репозиторий.

## Проверить перед сдачей

На странице GitHub должны быть исходники, requirements.txt, миграция, шаблоны и CSS. В списке commits должна быть перенесённая история, а `.venv`, `db.sqlite3`, `__pycache__` и `.idea` — отсутствовать. Сдай ссылку вида `https://github.com/ТВОЙ_ЛОГИН/studylog-vlasov-444`.

Новых коммитов ради числа делать не нужно: готовая история уже содержит больше восьми содержательных этапов. Исходная подпись существующих коммитов — Codex. Для собственных следующих изменений укажи свои данные только локально в этом репозитории:

```powershell
git config user.name "Никита Власов"
git config user.email "ТВОЙ_ПОДТВЕРЖДЁННЫЙ_EMAIL_ИЛИ_GITHUB_NOREPLY"
```

Не выполняй последнюю команду с текстом-заглушкой: возьми адрес из настроек своего GitHub. Это изменяет подпись будущих коммитов, а не вход в аккаунт.
